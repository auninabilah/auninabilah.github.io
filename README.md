# Auni Nabilah Portfolio

A dark, modern static portfolio inspired by the structure of the Daniel J Data Analyst Portfolio, adapted for:

- Computer Engineering
- IoT
- Embedded Systems
- Hardware + Software Integration
- Programming
- Automation

## Files

- `index.html` — page content
- `style.css` — design and responsive layout
- `script.js` — mobile menu, skill filters and hero text animation

## Before publishing

Replace the `#` links for LinkedIn and GitHub with Auni's real profiles.

Replace or refine the project descriptions with Auni's exact project details and add real project images.

## GitHub Pages

1. Create a GitHub repository named `auninabilah.github.io`.
2. Upload these three files.
3. Go to Settings → Pages.
4. Select the `main` branch and root folder.
5. Save and wait for GitHub Pages to publish the site.
