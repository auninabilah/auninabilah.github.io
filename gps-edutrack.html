GPS-Based EduTrack Pack

An IoT-oriented smart monitoring system combining real-time GPS location tracking and school bag weight monitoring to support student health and safety.

IoT GPS Embedded ESP32 Hardware Software

📋 About This Project

GPS-Based EduTrack Pack is a smart monitoring system designed to measure school bag weight and track student location in real-time. The system combines an ESP32, HX711, Load Cell and GPS module to collect and process information, while Telegram is used to provide notifications to parents.

☑ Key Features

  • Real-time student location tracking using GPS
  • Real-time school bag weight measurement
  • HX711 and Load Cell sensor integration
  • Telegram notifications for parents
  • Safe-zone monitoring for student location
